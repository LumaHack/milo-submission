# Milo v2 (branch `Antoine`)

Antoine's version, built on top of Ali's version on `main`. It lives in new files only: Ali's pages (`/`, `/session`, `/demo`, `/sheet`), his routes and his docs are unchanged, so both versions run side by side. Open v2 at `/v2`.

Everything in `docs/SPEC.md`, `docs/DESIGN.md` and `CLAUDE.md` still applies unless this page says otherwise.

## Why a v2

Antoine tested Ali's live session on Sat 14 Nov at 21:35. What he saw, confirmed by the ElevenLabs transcript of that run:

- A turn took about 13 s to redraw (Claude about 6 s, fal about 7 s). The final sheet took about 26 s.
- Milo's question lagged one turn behind. The student said "I think the mitochondria", and Milo then asked which part makes the energy. Approach A speaks the hint from the previous turn.
- Every line opened with "Mmhh… but", and tags such as "[puzzled]" were printed on screen.
- Milo said "Are you still there?" while the student was thinking or watching the board. Those silences were also sent to Claude as turns.
- When the student was stuck, Milo asked the same question again.
- The screen felt busy and did not show which ideas were still missing.

## What changes

| Area | v2 |
|---|---|
| Voice loop | Approach B. The agent calls the browser tool `update_board` when the student finishes a point. The tool has Claude score the turn and write Milo's line, and returns the line. Milo says it word for word. The drawing finishes in the background |
| Speed | The Claude call is tuned for speed (see Timing). fal's fast model draws every live board. The careful model draws only the polished sheet at the end |
| Modes | Picked on the start screen. **Coach**: Milo climbs a hint ladder when the student is stuck. **Exam**: Milo only asks open questions and never hints |
| Hint ladder | 0 a vague question. 1 point at the board, which now shows an empty dotted outline with a "?" where the missing part goes. 2 an everyday comparison. 3 two words to choose from. 4 Milo says the word, never what it does |
| Patience | Turn eagerness patient, the longest turn timeout, the skip-turn tool, never "are you still there". Silent or "..." turns are never scored |
| Structure | A checklist of the key ideas, written as questions, each with a status: not yet, getting there, got it, check this. Exam mode shows only how many are left |
| Pause | Pause hangs up the voice and keeps the board. Resume reconnects and Milo says welcome back. Reopening the page offers: pick up where you left off, or start fresh |
| End page | "Aha!": the final sheet, tidied by the careful model once every idea is clear, what you nailed in your own words, what to work on as questions, and every board in order to click through or replay |
| History | "How World War II started", drawn as a chain of falling dominoes: no people, flags, symbols or war scenes. Goes to `main` only if the team agrees |

## Run it

1. `.env.local` needs `ANTHROPIC_API_KEY`, `FAL_KEY` and `ELEVENLABS_API_KEY`. Milo v2 does not need an agent id there.
2. `pnpm dev`, then create or update Milo v2's agent once: `curl -X POST http://localhost:3000/api/v2/elevenlabs/setup`. Run it again after changing `src/lib/v2/agent.ts`.
3. Open http://localhost:3000/v2 in Chrome, pick a subject, a mode and a topic, allow the microphone. Wear headphones.

To test without a microphone, add one of these to the session address and type turns in the browser console:

- `&voice=text`: a typed chat with Milo's real agent, over a websocket. `window.miloSay("The Treaty of Versailles punished Germany.")` sends a turn; Milo calls `update_board`, the board redraws, his reply shows in the bubble. This tests the whole loop except sound. The skip_turn check-in does not run in a typed chat.
- `&voice=off`: no Milo at all. `window.miloSay(...)` scores a turn directly. `window.miloHear(...)` acts as if the voice agent heard a turn and Milo then did nothing, to test the safety net.

## Milo v2's agent

Created by `/api/v2/elevenlabs/setup` from `src/lib/v2/agent.ts`, named "Milo v2", separate from Ali's agent so both versions keep working. The token route finds it by name.

- LLM `claude-sonnet-5-5`, which ElevenLabs recommends for agents that call tools.
- Client tool `update_board`: waits for the browser's answer (30 s timeout), always says a few words before it runs ("Ooh, wait, I'm drawing that").
- `skip_turn` system tool, only when the student clearly asks for time ("wait", "let me think"). A pause, an "um" or a sentence that trails off ends the turn. After 15 s of silence Milo checks in calmly, never with "are you still there". Turn eagerness patient, turn timeout 30 s.
- Safety net in the page: if Milo has not called `update_board` 6 s after the student's turn, the page scores it and redraws the board itself, then passes Milo his line as a note.

**Fixed Sat 14 Nov, 23:00.** In Antoine's first voice test, he gave a long answer that trailed off ("So, that's, I think, the-"). Milo called `skip_turn`, because the prompt said to stay quiet when a student stops mid-sentence, and waited for him to speak again while he waited for Milo. The page only scored a turn once Milo spoke, so nothing was drawn either. Both are fixed. Checked in a typed chat with his exact words: Milo called `update_board`, said Claude's line word for word, and used `skip_turn` only for "Wait, let me think".
- First message `{{opening_line}}` and `{{topic_about}}`, set per session by the browser.
- Speech-to-text keywords for every topic's hard names, from "mitochondria" to "Sudetenland".
- Expressive tags such as "[curious]" are stripped before they reach the screen.

## The new session screen

`src/components/v2/session-view-v2.tsx`, layout from Antoine's mockups, look from the v3 tokens. A "Classic look" button in the header switches to Ali's session screen running the same session, and a "New look" button switches back. The choice is remembered.

- **Header**: the four crayon levels as steps, Classic look, End session.
- **What Milo gets** (left): one row per key idea, as its gap question, with Not yet, Getting there, Got it or Check this. In coach mode the gap Milo is asking about is highlighted. **Hide what's left** blurs the ideas not started yet (the text under the blur is scrambled). On by default in exam mode.
- **Board** (middle, biggest) with "Milo is drawing…" while fal works.
- **Milo** (right, overlapping the board card's edge, never the drawing): his line, one quiet line saying what he is doing, and Milo himself as a 3D cut-out standing beside the board, cut at the waist by the voice bar like a desk in front of him. He changes pose with what he is doing: listening, thinking (while Claude scores and fal draws), talking, pointing at the board (when his line gives a hint), and cheering (for 2.6 s when he grows up a level, and when everything is clear). Poses cross-fade; he still breathes, leans and bobs with his voice.
- **Voice bar**: mute, what you said last, Pause or Resume, Start again (asks to confirm), session clock. Pause hangs up the voice and stops the clock; Resume reconnects and Milo says welcome back.
- **Timeline**: every board with its time and a name ("First explanation", "One more idea clear", "Hint 1", "Final board"), click to look back, Replay.
- **Pick up where you left off**: the session is saved in the browser after every turn. Opening the same topic and mode again offers to pick up or start fresh.

- **End session** (header) and **See your sheet** (voice bar, appears once every idea is clear) both open the end page. If the last drawing is still on its way from fal, the button reads "Finishing the drawing…" and waits for it, at most 30 s, so the end page always has the final board.

## The end page

`/v2/end?topic=<id>&mode=<coach|exam>`, in `src/components/v2/end-view.tsx`. It reads the session saved in the browser. With no saved session it says so and links back.

- **Header**: the wordmark and the subject line. "Pick another topic", and "Explain it again", which clears the saved session and starts a new one on the same topic and mode.
- **Main card**: "Aha!" when every idea is clear, otherwise "Nice work" with "3 of 5 explained". "Save sheet". Then the final board, big.
- **Milo** at his final age: cheering with "That's all of it! I get it now.", or listening with "I still wonder about 2 things. Come back and tell me?". He never gives an answer.
- **Session summary**: explanations, ideas explained, hints used, time explaining, and the level reached as a chip.
- **What you nailed**: each clear idea as its question, with the student's own words under it.
- **What to work on**: each idea that is not clear, as its question, with Check this, Getting there or Not yet. Never the answer.
- **How your drawing grew**: every board from left to right with an arrow between them. Click one to see it in the main card ("Back to final board" returns). Replay plays them at 1.4 s each and ends on the final board. The strip scrolls sideways on a phone.

**The tidy sheet.** When every idea is clear, the page asks `/api/v2/draw` once, with `final: true`, to redraw the last board with fal's careful model (18.4 s on average over 3 runs). The old board stays up with "Milo is tidying your sheet" until the new picture has loaded. The link is kept with the saved session, so reopening the page costs nothing. If the call fails, the last board stays and nothing is said.

The instruction: "Keep the same drawing and the same content. Make it clean and organised like a finished revision sheet: neat lines, label boxes, and one title top left, spelled exactly: '<the topic's title>'. Give every part the same care: labels the same size, all easy to read. Do not add, remove or change any part, label or word. Do not add dates, numbers, question marks or shapes that are not already on the paper. No people, faces, flags, symbols or weapons."

**An unfinished board is not tidied.** Tested on Sun 15 Nov with a session at 2 of 5: asked to make it "a finished revision sheet", the careful model added a title of its own, "History revision: 1919-1933", with a year the student never said, and a new question mark. That breaks the rule that the drawing only shows what the student said. So an unfinished session keeps the board as Milo drew it, and the messy board stays honest feedback. To try it the other way, change `complete` in the tidy effect of `end-view.tsx`.

**The summary.** `POST /api/v2/summary`, one Claude call when the page opens (Opus 5.5, low effort, fast mode: 1.4 to 2.0 s over 4 runs, about $0.015). Claude returns, for each clear idea, a turn number and at most 15 words copied from that turn. The route then looks for those words in what the student really said, ignoring case and punctuation, and shows the matching stretch of the student's own turn. A pick that is not found word for word is dropped, and that idea is listed without words. So the summary cannot state a fact the student did not say. The result is kept with the saved session.

**Your revision sheets.** "Save sheet" adds the sheet to `milo.v2.sheets` in the browser: the picture's link, the title, and the nailed ideas with the student's words. `/v2/sheets` lists them, opens one big, and can remove one. Only the link is stored, so a sheet disappears if fal deletes the picture.

**Why some links load the whole page.** Next 16 keeps a page it navigated away from alive in the background and brings it back for the same address. "Explain it again" then reopened the finished session instead of a new one. So leaving a session through "End session", and every link that starts a session from the end page or a saved sheet, loads the page from scratch.

### Milo's poses

20 pictures in `public/milo-v2/<pose>-<stage>.png`: 5 poses at each of his 4 ages. Made on Sat 14 Nov by `POST /api/v2/dev/milo-poses`, which uploads each age's picture from `public/milo/`, has `fal-ai/nano-banana-pro/edit` redraw the same boy in the pose (about 20 s each), cuts him out with `fal-ai/birefnet/v2` (model "Matting"), and saves a transparent PNG. Then shrunk to 640 px wide. Three listening poses were redrawn once: one lost his graduation cap, two had a shoulder cut off.

Pointing makes Milo smaller in the picture, so `src/lib/v2/milo-poses.ts` stores where his head is in each picture and draws every pose with his head the same size and in the same place. Measure again after redrawing a pose.

## What "close enough" means

Each key idea in `src/lib/v2/topics.ts` has a **core**, what the student must get across, and a **term**, the proper word. Claude judges meaning, not wording, and an idea can build up over several turns. Dates and numbers beyond the core are a bonus, never required, and a wrong bonus detail does not change the status.

- **Coach mode**: everyday words count. "The skin of the cell decides what gets in and out" is clear.
- **Exam mode**: the term is needed too, in any spelling speech-to-text produces. In everyday words only, the idea is "getting there", and Milo asks what that thing is called.

Checked on Sat 14 Nov with 11 near-miss sentences in both modes: everyday wording counted in coach mode and was asked about in exam mode ("What's that skin called?"); misheard terms ("mighty-condria") counted in both; a wrong answer (Pearl Harbor as the start of the war) was marked "check this" in both, with a puzzled question instead of a correction.

## The v2 turn contract

Code: `src/lib/v2/contract.ts`. It adds to the shared contract in `docs/SPEC.md` without changing it.

- **Request** (`POST /api/v2/turn`): `topicId`, optionally `part` (the definition of a part of the student's own course, see `docs/COURSES.md`), `mode` (`coach` or `exam`), `studentTurns`, and the state before this turn: `previousLevel`, `previousIdeas`, `previousBiggestGapId`, `previousHintStep`, `previousDrawPrompt`, plus `recentMiloLines` so Milo varies how he starts.
- **Result**: `ideas`, `level`, `biggestGapId`, `hintStep` (0 to 4, always 0 in exam mode), `miloLine` (what Milo says next), `said`, `changed`, `drawPrompt`.
- **Draw** (`POST /api/v2/draw`): `prompt`, `previousImageUrl`, and `final`. The fast model draws every live board. `final: true` redraws the last board with the careful model, for the end page.
- **Summary** (`POST /api/v2/summary`, `src/lib/v2/summary.ts`): `topicId`, optionally `part`, `studentTurns`, and `ideas` with their statuses. Returns `nailed`: one entry per clear idea, with `words` (the student's own, or null).
- **Saved session** (`src/lib/v2/storage.ts`): two optional extras for the end page, `polished` (the tidy picture and the board it was made from) and `summary`. Both are dropped when the session carries on.

**What a night of testing cost.** In development every v2 route adds one line to `node_modules/.cache/milo/usage.jsonl` (git ignores it): the route, how long it took, token counts and dollars for Claude, the endpoint for fal. No keys, prompts or student words.

The rules in `docs/SPEC.md` still hold: the level never drops, `changed: false` means no fal call, one redraw in flight with the newest result winning, and the old board stays up until the new one has loaded.

## Timing

Measured on Sat 14 Nov, typed turns sent to `/api/v2/turn` on a laptop, one run per setting.

**Claude scoring one turn**, the four demo turns in coach mode:

| Setting | Average | Slowest |
|---|---|---|
| `claude-opus-5-5`, low effort | 6.8 s | 9.7 s |
| `claude-opus-5-5`, low effort, fast mode | **2.4 s** | 3.3 s |
| `claude-sonnet-5-5`, low effort | 3.1 s | 3.3 s |
| `claude-haiku-5-5`, low effort | 7.4 s | 9.4 s |

Chosen: Opus 5.5, low effort, fast mode. Same model as Ali's version, about three times faster, at twice the price per token. A stuck student in coach mode averaged 2.3 s a turn, and exam mode 1.9 s. If fast mode is rate limited, the route answers at standard speed. Turn it off with `V2_FAST_MODE=0`, or change the model with `V2_ANTHROPIC_MODEL`.

**fal, fast model**: first board 4.2 s, edits 6.4 to 6.9 s.

So a typed turn now takes about 6 to 9 s from text to new board, against 11 to 14 s before. The careful model (about 20 s) only runs once, for the end page.

**History boards**, the four example prompts in `src/lib/v2/topics.ts` drawn in order on Sat 14 Nov: 4.8, 7.1, 6.5 and 6.4 s on the fast model. All four came back as dominoes, with no people, flags or symbols. The fast model may have misspelled "Appeasement" on the dense level 4 sheet. The careful model redrew it in 18.9 s with every label right and the dominoes falling.
